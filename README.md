# Russian News Classifier (CLI)

Минимизированная версия проекта для обучения и использования бинарного классификатора
новостей ("Экономика" или "Не экономика") без Docker и веб-интерфейса.

## Возможности

- Обучение модели на собственном CSV-файле с новостями и категориями
- Предсказание принадлежности новости к экономической тематике из командной строки
- Гибкая настройка синонимов для экономической тематики и имён классов
- Хранение артефактов обучения (`model.cbm`, `vectorizer.pkl`, `label_encoder.pkl`, отчёт по качеству)

## Установка

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. При первом запуске будут автоматически загружены русские стоп-слова NLTK.

## Подготовка данных

Ожидаемый формат входного CSV:

- столбец с текстом новости (по умолчанию `title`)
- столбец с категорией (по умолчанию `topic`), где экономические новости
  отмечены значениями вроде `Экономика`, а прочие темы — любыми другими

Любые другие названия можно передать через параметры `--text-column` и `--target-column`.

## Обучение модели

```bash
python train.py path/to/dataset.csv \
  --text-column title \
  --target-column topic \
  --output-dir artifacts \
  --positive-label Экономика \
  --positive-label Финансы
```

Параметр `--positive-label` можно указывать несколько раз, добавляя синонимы,
которые будут считаться экономическими новостями. Названия выводимых классов
регулируются аргументами `--positive-class-name` и `--negative-class-name`
(по умолчанию — "Экономика" и "Не экономика").

После завершения обучения будут сохранены артефакты и отчёт `classification_report.json`
с метриками, распределением классов и сопоставлением индексов категориям.

## Предсказание категории

```bash
python predict.py artifacts --text "В Москве построили новый парк" --top-k 5
```

Скрипт выведет окончательный ответ ("Экономика" или "Не экономика") и распределение
вероятностей по классам.

## Структура проекта

```
├── artifacts/          # директория для сохранения артефактов (пустая)
├── news_classifier/    # пакет с кодом обучения и инференса
├── predict.py          # CLI для получения предсказаний
├── requirements.txt    # зависимости для локального запуска
└── train.py            # CLI для обучения
```

## Обновление словаря экономических тем

Чтобы учесть новые формулировки для экономических новостей, перезапустите обучение
с дополнительными параметрами `--positive-label`. Модель автоматически
переобучится и сохранит обновлённые артефакты.
