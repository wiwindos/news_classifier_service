# Russian News Classifier (CLI)

Минимизированная версия проекта для обучения и использования бинарного классификатора
новостей ("Экономика" или "Не экономика") без Docker и веб-интерфейса.

## Возможности

- Обучение модели CatBoost на собственном CSV-файле с новостями и категориями
- Автоматическая предобработка текстов (токенизация, удаление стоп-слов, TF-IDF)
- Гибкая настройка синонимов и отображаемых названий классов
- Сохранение всех артефактов обучения (`model.cbm`, `vectorizer.pkl`, `label_encoder.pkl`, `classification_report.json`)
- CLI-утилита для мгновенного получения предсказания и распределения вероятностей

## Быстрый старт

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

   ```bash
   .\.venv\Scripts\Activate.ps1   
   pip install -r requirements.txt
   ```

3. При первом запуске будут автоматически загружены русские стоп-слова NLTK.

## Подготовка данных

Ожидаемый формат входного CSV:

- столбец с текстом новости (по умолчанию `title`)
- столбец с категорией (по умолчанию `topic`), где экономические новости
  отмечены значениями вроде `Экономика`, а прочие темы — любыми другими

Название столбцов можно переопределить аргументами `--text-column` и `--target-column`.
Список значений, которые считаются экономическими, задаётся через `--positive-label`
(аргумент можно передавать несколько раз).

## Обучение модели

```bash
python train.py path/to/dataset.csv \
  --text-column title \
  --target-column topic \
  --output-dir artifacts \
  --max-features 15000 \
  --iterations 500 \
  --positive-label Экономика \
  --positive-label Финансы \
  --positive-class-name "Экономика" \
  --negative-class-name "Не экономика"
```

Основные параметры CLI:

| Параметр | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `--output-dir` | Куда сохранять артефакты обучения | `artifacts/` |
| `--max-features` | Количество признаков в TF-IDF | `10000` |
| `--test-size` | Доля данных для валидации | `0.2` |
| `--random-state` | Фиксация случайности для воспроизводимости | `42` |
| `--iterations` | Количество итераций бустинга CatBoost | `400` |
| `--learning-rate` | Скорость обучения CatBoost | `0.1` |
| `--positive-label` | Синонимы экономической тематики (можно несколько) | `Экономика`, `economics`, `economy` |
| `--positive-class-name` / `--negative-class-name` | Отображаемые имена классов | `Экономика` / `Не экономика` |

После завершения обучения будут сохранены:

- сама модель CatBoost (`model.cbm`)
- TF-IDF-векторизатор (`vectorizer.pkl`)
- кодировщик классов (`label_encoder.pkl`)
- JSON-отчёт `classification_report.json` с метриками, распределением классов и списком синонимов

## Предсказание категории

```bash
python predict.py artifacts --text "В Москве построили новый парк" --top-k 5
```

Скрипт выведет итоговый класс и вероятности (по умолчанию показываются три
самых вероятных класса, можно изменить `--top-k`). Для корректной работы в
директории с артефактами должны находиться файлы, полученные после обучения.

## Структура проекта

```
├── artifacts/          # директория для сохранения артефактов (пустая)
├── news_classifier/    # пакет с кодом обучения и инференса
├── predict.py          # CLI для получения предсказаний
├── requirements.txt    # зависимости для локального запуска
└── train.py            # CLI для обучения
```

## Обновление словаря экономических тем

Чтобы учесть новые формулировки для экономических новостей, переобучите модель
с дополнительными аргументами `--positive-label`. Новые артефакты автоматически
перезапишут старые в указанной директории.
